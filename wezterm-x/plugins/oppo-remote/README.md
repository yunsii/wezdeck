# oppo-remote

OPPO 互联 (O+ Connect) remote-control link quality: the `OppoRemote·` badge,
the `wezterm-oppo-remote.service` sampler, and the `oppo-remote-quality.sh`
report / timeline / watch / episodes CLI.

Operator doc (triage order, incident history, signal meanings):
[`docs/oppo-remote-host-input.md`](../../../docs/oppo-remote-host-input.md).

```bash
wezterm-x/plugins/oppo-remote/bin/install.sh            # install the sampler
wezterm-x/plugins/oppo-remote/bin/oppo-remote-quality.sh report
```
