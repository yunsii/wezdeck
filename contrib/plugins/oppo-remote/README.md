# oppo-remote (contrib)

Optional WezDeck plugin: OPPO 互联 (O+ Connect) remote-control link quality —
`OppoRemote·` badge, background sampler, and a report / timeline / watch /
episodes CLI built from O+ Connect's own logs. Off unless enabled per machine.

Docs: [`docs/oppo.md`](docs/oppo.md). Tests: `tests/run.sh` (run by the core
suite via `tests/hook-units/test_contrib_plugins.sh`).
